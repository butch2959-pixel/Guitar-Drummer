# Guitar Drummer Web Prototype 1

A browser-based prototype for iPhone Safari.

## Run
The browser must receive the site over HTTPS (or localhost during development) for microphone access.

Upload these files to any HTTPS static web host, then open the site's `index.html` URL on your iPhone.

## What it does
- Requests microphone access
- Displays live input level
- Estimates BPM from guitar attacks
- Generates simple kick/snare/hi-hat patterns
- Rock, Blues, Country and Funk styles
- Intensity control

This is intentionally an early prototype. The next version should use a real beat tracker and better drum synthesis/samples.
